See it work

A complete example.

Create an agent, give it a budget, and make a payment-aware request in minutes.

bash 
# 1. Create a key for your agent
$ tab key new --out keys/agent.json

✓ wrote keys/agent.json  (agent_8f3c…)
bash 
# 2. The owner signs a mandate, once, offline
$ tab mandate issue --owner keys/owner.json \
    --agent keys/agent.json --budget 1.00 --max-per-call 0.05

✓ wrote keys/mandate.json  ($1.00 budget, $0.05 per call)
bash 
# 3. The agent pays per request under that mandate
$ tab fetch --agent keys/agent.json --mandate keys/mandate.json \
    http://127.0.0.1:1402/quote

✓ Paid $0.01
✓ Response: 200 OK
json 
// 4. Every paid call returns a signed receipt
{
  "resource": "GET /quote",
  "amount":   "0.01",
  "rail":     "ledger",
  "ref":      "ledger:a91f…"
}

Then the agent can pay for real services.

bash 
$ tab fetch https://api.example.com/translate \
    -X POST \
    -d '{"text":"Hello"}'

✓ Paid $0.002
✓ Response: 200 OK
