You sign the limit once. tab enforces it on every request, and the agent can never exceed it.

Built on HTTP.

A service says what it costs with a 402. The agent pays inline and gets the answer. No accounts, no API keys, no invoices.

The exchange

One retry, one payment, one receipt. Every step is a plain HTTP header.

GET /v1/translate
→ 402 Payment Required
  WWW-Authenticate: Tab challenge="…"   price 0.004 USD

GET /v1/translate
Authorization: Tab <signed credential>
→ 200 OK
  Tab-Receipt: … ref evm:0x3f9c…

Three commands

Price your API in a JSON spec and put tab in front of it. Sign a limit for an agent and let it pay.

# provider: price your routes, start the gateway
$ tab serve --spec spec.json

# owner: sign a limit for your agent, once
$ tab mandate issue --owner owner.json --agent agent.json \
    --budget 25 --max-per-call 0.05

# agent: pay per request under that limit
$ tab fetch --agent agent.json --mandate mandate.json \
    https://api.lingua.example/v1/translate
✓ paid $0.004 · 200 OK
